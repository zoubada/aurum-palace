# Tour du lac d'Annecy — données du circuit

Généré par `tools/annecy/` à partir de :
- © contributeurs OpenStreetMap (ODbL) — routes, lac, bâtiments, panneaux ;
- IGN, RGE ALTI et BD ORTHO (Licence Ouverte 2.0) — relief, modèle de surface, photos aériennes.

Fichiers : `track.json` (tracé, lac, panneaux, variantes), `t/<i>_<j>.bin` (case de 1 km :
hauteurs, arbres, bâtiments ; compressé gzip), `t/<i>_<j>.webp` (photo aérienne), `far.*`
(montagnes autour du lac, 48 km).
